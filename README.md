# CCTV Monitoring Portal

Next.js + TypeScript + Tailwind, API Fastify TypeScript, PostgreSQL, MediaMTX.
Lihat [arsitektur](docs/architecture.md), [pengembangan](docs/development.md),
[deployment](docs/deployment.md), dan [keamanan](docs/security.md).

Tidak ada kredensial bawaan. Seluruh kamera baru privat dan tidak disetujui
untuk publik. Integrasi perangkat produksi membutuhkan konfigurasi dan persetujuan
operator; repositori ini tidak mengubah router atau NVR.
